# Belajar HTML & CSS

Repository ini digunakan sebagai tempat untuk menyimpan latihan dan proses pembelajaran **HTML (HyperText Markup Language)** dan **CSS (Cascading Style Sheets)**.

## Deskripsi

Repository **belajar-html-css** berisi kumpulan latihan dasar dalam membuat halaman website menggunakan HTML dan CSS.

HTML digunakan untuk membuat struktur dan isi dari sebuah halaman website, sedangkan CSS digunakan untuk mengatur tampilan, warna, ukuran, jarak, dan tata letak dari halaman tersebut.

Repository ini dibuat sebagai dokumentasi proses belajar serta tempat untuk menyimpan hasil latihan yang telah dikerjakan.
